# Serena Antonietta – The First Descendant (Fanseite)

Live: **https://serena.freyna.org/**

Inoffizielle, KI-lesbare Fanseite über die Descendant **Serena** (offizieller voller Name: **Serena Antonietta**, laut Nexon-Patchnotes Update 1.2.10) aus *The First Descendant* (Nexon):
Überblick, Fakten, Werte auf Lv 40 (Max-Level), alle Fertigkeiten, Serenas eigene Module auf Lv 10 (Archangel, Battlefield Nun, Hymn, Divine Surge, Hope's Resolution), Endgame-Builds (Archangel, Battlefield Nun, Hymn-Gunner) mit Modulen, Waffen, Reaktor, externen Komponenten, Kernen und Arche-Tuning, Story und Forschung.

- Offizielle Daten: [NEXON LIBRARY – SERENA](https://tfd.nexon.com/en/library/descendants/101000027), Nexon-Patchnotes und die Metadaten der [NEXON OPEN API](https://openapi.nexon.com/game/tfd/).
- Build-Empfehlungen stammen aus genannten Community-Quellen (TFDHub, Gameslantern, AlcastHQ) mit Datum; Community-Zahlen sind auf der Seite als solche gekennzeichnet.
- Alle Werte auf Max-Level: Descendant Lv 40, Module auf maximaler Verbesserungsstufe, Waffen Lv 100 mit 4 Sternen (Transzendente Waffen: Lv 100, Qualität 400), Reaktoren und externe Komponenten Lv 100.
- Nicht überprüfbare Angaben (z. B. Prozentwerte von Archangel/Battlefield Nun) werden bewusst nicht aufgeführt.
- Eine einzige `index.html`, Inline-CSS, kein JavaScript (nur JSON-LD), semantisches HTML mit Tabellen.
- Klartext für KIs: [`LLMS.TXT`](https://serena.freyna.org/llms.txt), [`LLMS-FULL.TXT`](https://serena.freyna.org/llms-full.txt).
- Header-Bild `serena.jpg`: KI-generiert mit Grok Imagine.
